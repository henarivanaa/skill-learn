# Catatan penggunaan AI

Jenis penggunaan pada soal: Integrated.

Alat yang dipakai: Cursor, dengan model Grok, untuk merencanakan arsitektur jawaban, menulis draf soal 1–3, dan membuat kode SkillLearn (server Express, web React, dan mobile Expo).

Yang tetap menjadi tanggung jawab pengumpul:

- memeriksa kebenaran jawaban dan kode sebelum dikumpulkan
- memahami alur daftar, masuk, materi, favorit, riwayat, dan kuis
- mengisi formulir deklarasi resmi kampus
- menempel jawaban pada lembar jawaban, bukan hanya pada file ini
- mengisi tautan Figma, hosting, dan kode setelah deploy dilakukan sendiri

Pernyataan yang dapat dipindahkan ke formulir deklarasi:

Saya menggunakan alat AI terintegrasi pada tahap perencanaan, penyusunan draf jawaban soal analisis, dan implementasi aplikasi SkillLearn. Saya meninjau hasilnya, menjalankan aplikasinya, dan bertanggung jawab atas isi yang dikumpulkan.
